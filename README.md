# Bodhi Rural Digital Platform

First Vercel-ready prototype for Bodhi Rural Livelihood & Agri Private Limited.

## Included
- Public corporate website
- BodhiFarm module interface
- BodhiMart product catalog and demo cart
- Role-based demo login
- Management dashboard
- Mobile responsive UI
- Sample farmer/product data

## Phase 2
Connect Supabase/PostgreSQL, real authentication, row-level security, storage, live orders, payments and audit logs.

## Deploy
Import this repository into Vercel as a Next.js application. No environment variables are required for the demo version.
